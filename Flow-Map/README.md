# Flow Map

## Overview

This repository contains an academic Flow Map created using **ArcMap 10.7.1** as part of my B.Sc. Geoinformatics coursework. The project demonstrates the visualization of movement between locations using directional flow lines of varying widths.

## Objective

To represent the movement of people, goods, or services between geographic locations using flow lines, helping to visualize direction, volume, and spatial connectivity.

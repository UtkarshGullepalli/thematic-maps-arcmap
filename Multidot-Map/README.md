# Multidot Map

## Overview

This repository contains an academic Multidot Map created using **ArcMap 10.7.1** as part of my B.Sc. Geoinformatics coursework. The project demonstrates the use of multidot mapping to represent the spatial distribution of quantitative data.

## Objective

To represent the distribution of a variable using multiple dots, where each dot corresponds to a fixed quantity, making it easier to visualize spatial patterns and density.

# Grayscale Map

## Overview

This repository contains an academic Grayscale Map created using **ArcMap 10.7.1** as part of my B.Sc. Geoinformatics coursework. The project demonstrates the use of grayscale colour gradients to visualize spatial variation in geographic data.

## Objective

To represent the distribution and intensity of a geographic variable using different shades of gray, making spatial patterns easy to interpret without relying on colour.

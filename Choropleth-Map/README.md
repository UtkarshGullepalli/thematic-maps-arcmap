# Choropleth Map

## Overview

This repository contains an academic Choropleth Map created using **ArcMap 10.7.1** as part of my B.Sc. Geoinformatics coursework. The project demonstrates the use of graduated colour shading to represent variations in statistical data across administrative boundaries.

## Objective

To visualize the spatial distribution of a quantitative variable by applying different colour intensities to geographic regions based on their attribute values.

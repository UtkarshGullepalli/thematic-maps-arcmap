# GIS Thematic Maps using ArcMap

## Overview

This repository contains a collection of thematic maps created using **ArcMap 10.7.1** as part of my B.Sc. Geoinformatics coursework. These maps were developed to understand cartographic design principles, thematic visualization techniques, and fundamental GIS concepts.

## Software Used

- ArcMap 10.7.1

## Thematic Maps

- Monodot Map
- Multidot Map
- Choropleth Map
- Chorochromatic Map
- Grayscale Map
- Isopleth Map
- Flow Map
- Point Symbol Map
- Buffer Analysis
- Tourism Map

## Purpose

The objective of this repository is to document my academic learning in thematic mapping and demonstrate fundamental GIS cartographic skills using ArcMap.

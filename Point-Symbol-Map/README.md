# Point Symbol Map

## Overview

This repository contains an academic Point Symbol Map created using **ArcMap 10.7.1** as part of my B.Sc. Geoinformatics coursework. The project demonstrates the use of point symbols to represent the locations and characteristics of discrete geographic features.

## Objective

To visualize the spatial distribution of point-based geographic features using symbols, enabling clear representation of locations and associated attributes.

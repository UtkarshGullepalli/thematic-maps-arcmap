# India Tourism Map

## Overview

This repository contains an academic India Tourism Map created using **ArcMap 10.7.1** as part of my B.Sc. Geoinformatics coursework. The project demonstrates the visualization of major tourist destinations across India using GIS-based cartographic techniques.

## Objective

To represent the spatial distribution of major tourist attractions across India using thematic mapping techniques, enabling easy visualization of tourism locations.

## Study Area

India

## Software Used

- ArcMap 10.7.1

## Mapping Technique

- Tourism Mapping
- Point Feature Mapping

## Skills Demonstrated

- Thematic Mapping
- Point Symbolization
- Cartographic Design
- Data Visualization
- Map Layout Design

## Output

The final India Tourism Map is included in this repository.

## Note

This project was completed for academic learning purposes and demonstrates the application of GIS cartographic techniques for visualizing tourism-related spatial information.

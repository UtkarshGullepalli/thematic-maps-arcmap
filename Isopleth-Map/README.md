# Isopleth Map

## Overview

This repository contains an academic Isopleth Map created using **ArcMap 10.7.1** as part of my B.Sc. Geoinformatics coursework. The project demonstrates the representation of continuous spatial phenomena using contour lines that connect points of equal value.

## Objective

To visualize the spatial distribution of a continuous geographic variable by connecting locations with equal attribute values using isopleths.

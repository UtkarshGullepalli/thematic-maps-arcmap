# Monodot Map

## Overview

This repository contains an academic Monodot Map created using **ArcMap 10.7.1** as part of my B.Sc. Geoinformatics coursework. The project was developed to understand the principles of thematic mapping and cartographic representation in GIS.

## Objective

To visualize the spatial distribution of a single variable using a monodot mapping technique.

## Study Area

*Andhra Pradesh*

## Software Used

- ArcMap 10.7.1

## Mapping Technique

- Monodot Mapping

## Skills Demonstrated

- Thematic Mapping
- Cartographic Design
- Data Visualization
- Map Layout Design
- Symbolization

## Output

The final thematic map is included in this repository.

## Note

This project was completed for academic learning purposes and demonstrates the application of fundamental GIS cartographic techniques using ArcMap.

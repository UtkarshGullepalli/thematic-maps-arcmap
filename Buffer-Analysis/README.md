# Buffer Analysis

## Overview

This repository contains an academic Buffer Analysis project created using **ArcMap 10.7.1** as part of my B.Sc. Geoinformatics coursework. The project demonstrates the use of buffer analysis to identify areas within a specified distance of geographic features.

## Objective

To create buffer zones around geographic features and analyze the areas of influence or proximity for spatial decision-making.
